# Set up the local profile

## Use this when

- The profile is empty or the user wants more relevant role discovery.

## Steps

1. Open **Profile** and review existing values before proposing changes.
2. Start with target roles, level, locations, and work modes; optional fields can remain blank.
3. Add company preferences, career direction, and values only to the level the user finds useful.
4. Capture technologies to emphasize or exclude without inventing preferences.
5. Summarize the values that will be stored locally, then have the user review and save them.

## Done when

- The page confirms the local profile was saved and the user agrees it represents their current search.
