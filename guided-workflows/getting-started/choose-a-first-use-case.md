# Choose a first use case

## Use this when

- The app is empty, or the user does not yet know which feature will help.

## Steps

1. Ask what would be most valuable today: evaluate a role, find a referral path, organize preparation, or understand current progress.
2. Inspect the relevant page state and identify the smallest prerequisite.
3. Recommend one primary workflow and up to two alternatives, each with an outcome and time estimate.
4. Explain any local data the chosen workflow will need before starting it.

## Done when

- One use case and its next workflow are explicitly selected.
