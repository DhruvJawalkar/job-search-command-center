# Orient to the current page

## Use this when

- The user is unfamiliar with the page or asks what to do here.

## Steps

1. Identify the page from the portal URL hash and confirm the app is connected or in preview.
2. Summarize the page’s purpose in two sentences using the visible data, not a generic product tour.
3. Point out the strongest signal, empty state, or due item on the page.
4. Read that page’s workflow index and offer its three most relevant outcomes with time estimates.
5. Wait for the user to choose; do not start multiple workflows.

## Done when

- The user understands the page and has selected a workflow or chosen to browse independently.

## Boundaries

- Do not change data during orientation.
