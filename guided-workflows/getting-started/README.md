# Getting started workflows

Use this index when the user has not chosen a page or wants help deciding where to begin.

| Order | Workflow | Outcome | Time | Prioritize when |
| --- | --- | --- | --- | --- |
| 1 | [Orient to the current page](orient-to-current-page.md) | Explain the visible page and choose one useful action. | 2–3 min | The request is broad or the UI is unfamiliar. |
| 2 | [Choose a first use case](choose-a-first-use-case.md) | Select the shortest path to the user’s current goal. | 3–5 min | The workspace is empty or the user is unsure where to start. |
| 3 | [Set up the local profile](set-up-local-profile.md) | Save enough preferences to improve relevance. | 5–8 min | Role and search preferences are missing or stale. |

Offer these three in this order unless visible state makes a later option clearly more useful.
