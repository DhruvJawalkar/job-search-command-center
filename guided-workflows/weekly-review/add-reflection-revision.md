# Add a reflection revision

## Steps

1. Select the intended weekly snapshot and read its latest reflection.
2. Ask what new evidence or changed understanding prompted the revision.
3. Draft concise notes for what worked, what did not, and the next adjustment.
4. Show how the revision differs from the prior entry.
5. Save only after the user confirms it should be appended.

## Done when

- A new numbered revision appears and the earlier reflection remains intact.
