# Create a weekly snapshot

## Steps

1. Review the live date range, completeness, and key metrics with the user.
2. Explain that later activity will not rewrite the frozen measurements.
3. If desired, capture a concise “worked” and “improve” reflection before freezing.
4. Use **Freeze current snapshot** only after the user confirms the evidence is ready.
5. Verify the record appears in preserved history with the expected timestamp.

## Done when

- An immutable snapshot is visible in review history and its scope is understood.
