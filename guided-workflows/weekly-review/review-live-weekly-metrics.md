# Review live weekly metrics

## Steps

1. Confirm the week range and effective-through date in the live preview.
2. Review applications, outreach, pipeline progress, preparation delivery, and overdue actions.
3. Identify one positive signal, one bottleneck, and any missing data that could distort the view.
4. Propose up to three adjustments for the next week.
5. Ask whether the user is ready to preserve the snapshot or wants to correct tracking first.

## Done when

- The user understands the live metrics and has chosen whether they are ready to freeze.
