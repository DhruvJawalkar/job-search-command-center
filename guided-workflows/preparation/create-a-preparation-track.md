# Create a preparation track

## Steps

1. Review current tracks to avoid creating a duplicate.
2. Choose one outcome tied to a target role, interview need, or skill backlog item.
3. Give the track a concrete name, category, and definition of useful evidence.
4. Add one small first story that can be completed and demonstrated.
5. Review the scope with the user, save it, and confirm it appears in the portfolio.

## Done when

- A distinct track exists with a clear outcome and first actionable story.
