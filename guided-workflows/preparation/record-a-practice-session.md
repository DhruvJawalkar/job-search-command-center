# Record a practice session

## Steps

1. Select the exact preparation task that was practiced.
2. Capture the session type, duration, result, confidence, and evidence location.
3. Write a concise result summary that distinguishes completion from partial progress.
4. Add one next step if further work is needed.
5. Review the record with the user, save it, and update task status only if accurate.

## Done when

- The session appears in recent practice evidence with an honest result and next step.
