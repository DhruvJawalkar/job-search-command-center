# Plan a two-week sprint

## Steps

1. Review the backlog, active tracks, available time, and any interview deadlines.
2. Select a small number of tasks that produce complementary evidence.
3. Break oversized items down until each has a clear completion condition.
4. Order work by dependency and value, then check that the plan fits two weeks.
5. Let the user approve the set before starting or changing the sprint.

## Done when

- The active sprint has an achievable task set, order, and evidence expectations.
