# Review sprint progress

## Steps

1. Compare planned tasks with completed tasks and recorded practice evidence.
2. Identify blocked, oversized, or low-value work without treating activity as completion.
3. Recommend finish, split, defer, or remove for each selected item.
4. Review any carry-forward work before closing the sprint.
5. Save only the status and priority changes the user approves.

## Done when

- The sprint accurately reflects completed evidence and has a deliberate plan for remaining work.
