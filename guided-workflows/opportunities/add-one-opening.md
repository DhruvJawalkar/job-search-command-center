# Add one opening

## Steps

1. Ask for the listing URL or the company, role title, and any available description.
2. Open **Add opportunity** and fill only verified fields; label unknown details rather than guessing.
3. Review the company, title, location, work mode, source, and description with the user.
4. Save the record and confirm it appears in the openings view.
5. Offer either **Review and decide** or **Find a trusted contact** next.

## Done when

- The opening is visible in the current openings list and can be selected on Network.
