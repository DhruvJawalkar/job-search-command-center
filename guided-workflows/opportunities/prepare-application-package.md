# Prepare an application package

## Steps

1. Confirm the opening has been reviewed and the user wants to prepare—not submit—an application.
2. Review the source description and choose an existing resume variant or create the intended version outside the app.
3. Start the application and attach the exact resume PDF and job-description text for preservation.
4. Review artifact names, hashes, stage, and next action before saving.
5. Confirm the application remains a local draft unless the user records another stage.

## Done when

- A draft application exists with its exact resume and job description preserved locally.

## Boundaries

- Stop before opening or submitting an employer application form unless the user explicitly asks to continue.
