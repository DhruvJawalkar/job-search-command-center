# Opportunities workflows

| Order | Workflow | Outcome | Time | Prioritize when |
| --- | --- | --- | --- | --- |
| 1 | [Add one opening](add-one-opening.md) | Capture a real opening for review. | 3–5 min | No openings are present or the user has one listing. |
| 2 | [Review and decide](review-and-decide.md) | Make a supported shortlist, referral, apply, or skip decision. | 5–10 min | Openings are visible and awaiting review. |
| 3 | [Import daily files](import-daily-files.md) | Import a reviewed workbook and optional actions file. | 5–8 min | Daily files exist in the workspace. |
| 4 | [Resolve inbox and duplicates](resolve-inbox-duplicates.md) | Convert intake candidates into clean opportunity records. | 5–10 min | Inbox review has pending candidates or duplicates. |
| 5 | [Prepare an application package](prepare-application-package.md) | Preserve a resume and job description before applying. | 8–12 min | A shortlisted opening is ready for application work. |

Do not recommend application preparation before the opening has been reviewed.
