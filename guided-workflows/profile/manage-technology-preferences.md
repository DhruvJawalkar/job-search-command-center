# Manage technology preferences

## Steps

1. Review current inclusions, exclusions, and recent mismatched openings.
2. Distinguish technologies the user wants to build with from skills they merely possess.
3. Add exclusions only for genuine constraints; avoid filtering adjacent terminology accidentally.
4. Check for contradictions between included and excluded concepts.
5. Present the revised values and save them only after user review.

## Done when

- Technology preferences are internally consistent and explain recurring accept/reject decisions.
