# Configure search preferences

## Steps

1. Review existing values and preserve any useful details already present.
2. Confirm target roles and level first.
3. Add acceptable locations, work modes, company types, and company sizes.
4. Capture only strong technology inclusions or exclusions; leave uncertainty blank.
5. Summarize the proposed profile, let the user edit it, then save locally.

## Done when

- The saved profile provides enough constraints to judge whether an opening is relevant.
