# Find a trusted contact

## Steps

1. Confirm the correct opening in **Referral path finder**.
2. Review local contacts and referral candidates before searching externally.
3. If needed, use focused LinkedIn searches for alumni, recruiters, engineering managers, or engineers; explain that LinkedIn is external.
4. Compare candidates by relationship strength, relevance, recency, and ability to speak credibly about the role.
5. Recommend one primary contact and one fallback, stating the evidence and uncertainty.

## Done when

- The user has selected a credible contact or decided that no responsible referral path is available.

## Boundaries

- Do not send a connection request or message. Do not infer a relationship that the user has not confirmed.
