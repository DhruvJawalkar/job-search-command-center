# Review outreach follow-ups

## Steps

1. Filter active outreach by overdue first, then awaiting reply and planned drafts.
2. Verify what actually happened outside the app before changing any status.
3. Recommend close, follow up, reschedule, or record response based on timing and context.
4. Draft a follow-up only when useful and have the user review it.
5. Save accurate local status and next-action dates.

## Done when

- Selected outreach records reflect reality and each open item has a clear next step.

## Boundaries

- Never mark a message sent or a referral secured without the user confirming the external event.
