# Draft an outreach message

## Steps

1. Confirm the opening, recipient, relationship, channel, and desired ask.
2. Choose the closest built-in template scenario rather than starting with a generic pitch.
3. Personalize only with facts the user confirms; keep the request proportionate to the relationship.
4. Check tone, length, accuracy, and whether a lower-friction ask would be more appropriate.
5. Present the final draft for review and let the user decide whether to copy or save it.

## Done when

- The user has an approved draft and knows that it has not been sent.

## Boundaries

- Never click Send, submit a connection request, or imply endorsement without explicit instruction at that point.
