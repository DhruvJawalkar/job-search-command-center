# Network workflows

| Order | Workflow | Outcome | Time | Prioritize when |
| --- | --- | --- | --- | --- |
| 1 | [Find a trusted contact](find-a-trusted-contact.md) | Identify and assess the strongest referral path. | 5–10 min | An opening is selected and no path is saved. |
| 2 | [Draft an outreach message](draft-an-outreach-message.md) | Produce a personalized draft for user review. | 5–8 min | A recipient or contact type is known. |
| 3 | [Save a referral path](save-a-referral-path.md) | Record the chosen contact and planned next step locally. | 3–5 min | A credible contact has been identified. |
| 4 | [Import LinkedIn connections](import-linkedin-connections.md) | Load a reviewed export into the local workspace. | 5–10 min | The user has a LinkedIn connections CSV. |
| 5 | [Review outreach follow-ups](review-outreach-follow-ups.md) | Triage planned, sent, and overdue outreach. | 5–10 min | Outreach activity already exists. |

Never send a connection request, InMail, referral request, or follow-up without explicit user review and instruction.
