# Save a referral path

## Steps

1. Verify the selected opening and the person’s identity, company, title, and relationship.
2. Separate confirmed facts from notes or assumptions.
3. Choose the appropriate relationship strength and outreach type with the user.
4. Add a concrete next action and follow-up date if outreach is planned.
5. Save locally and confirm the path appears under the selected opening.

## Done when

- The referral path and next action are visible in the local Network workspace.

## Boundaries

- A planned outreach record is not evidence that a message was sent.
