# Capture skill evidence

## Steps

1. Start with proposed items in the human-validation queue.
2. Read the quoted evidence in its company and role context.
3. Check whether the canonical skill and strength are supported by the text.
4. Ask the user to accept, correct, or reject each selected item; avoid bulk acceptance when evidence differs.
5. Verify the reviewed count and resulting catalog changes.

## Done when

- Selected evidence has an explicit human-reviewed status and accurate canonical mapping.
