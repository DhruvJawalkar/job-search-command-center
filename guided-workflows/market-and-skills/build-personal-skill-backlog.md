# Build a personal skill backlog

## Steps

1. Review existing backlog items before adding new ones.
2. Compare market frequency, target-role importance, current confidence, and career direction.
3. Select no more than three near-term skills; defer attractive but low-relevance topics.
4. Define why each matters and what observable evidence would show improvement.
5. Save the ordered backlog after the user reviews priorities.

## Done when

- The backlog has a deliberate top three with evidence-based rationale.
