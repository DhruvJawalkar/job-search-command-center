# Review application follow-ups

## Steps

1. Sort the visible follow-ups by overdue status, deadline, and application stage.
2. Start with the most urgent application and verify its current status.
3. Propose a specific next action and date; ask the user to correct assumptions.
4. Update the local record only after the user reviews the proposed value.
5. Repeat only for the items the user wants to handle now.

## Done when

- Each selected application has an accurate next action and follow-up date.

## Boundaries

- Updating local tracking does not authorize sending an email, contacting a recruiter, or submitting a form.
