# Choose the next workspace

## Steps

1. Compare visible due work, empty states, and current pipeline bottlenecks.
2. Recommend one destination: Opportunities, Network, Market & skills, Preparation, Weekly review, or Profile.
3. Explain the outcome available there and why it is more useful than the alternatives now.
4. Navigate only after the user agrees, then load that page’s workflow index.

## Done when

- The user is on the selected page with one workflow ready to begin.
