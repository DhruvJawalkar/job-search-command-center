# Understand the command center

## Steps

1. Explain the personalized briefing, its current evidence source, and the selected recommendation emphasis.
2. Walk through today’s priorities, application follow-ups, pipeline, schedule, and stored artifacts.
3. Distinguish live values from imported or recommended values.
4. Point out that **Customize Summary** controls recommendation emphasis, insight cards, the weekly application goal, specialization, top-three priority sources, and the daily schedule.
5. Call out one signal that deserves attention and one area that can safely wait.
6. Offer up to three relevant page workflows.

## Done when

- The user can explain what the Summary is telling them and which signal they want to act on.
