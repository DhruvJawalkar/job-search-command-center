# Contributing

Thank you for improving Job Search Command Center.

Before proposing a change:

1. Keep examples synthetic and remove personal data, credentials, account exports, resumes, notes, and database contents.
2. Preserve the localhost-only trust boundary unless a reviewed authentication and authorization design is part of the proposal.
3. Add or update tests for changed behavior.
4. Run the backend tests and frontend lint/build/test commands documented in `docs/DEVELOPMENT.md`.
5. Explain the user outcome, security impact, migration impact, and validation evidence in the pull request.

By submitting a contribution, you represent that you have the right to provide it and agree that it may be distributed with the project under its current source-available license. Contribution does not grant permission to present a fork or modified distribution as official.
