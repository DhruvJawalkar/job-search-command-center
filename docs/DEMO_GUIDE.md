# V1 demo guide

Use a dedicated local workspace and choose **synthetic demo content** during setup. Never record a demo in a workspace containing personal resumes, contacts, account exports, or real application history.

## Guided product walk-through

1. **Setup and trust boundary** — show the folder choice, empty/demo choice, generated local structure, loopback URL, and visible synthetic-data banner.
2. **Summary** — explain the morning briefing, three priorities, application follow-ups, pipeline health, and first-use path.
3. **Opportunities** — inspect ranked openings, evidence, recommendation, resume choice, import history, and replay-safe synchronization.
4. **Network** — demonstrate referral-path research, an editable profile-aware message draft, tracked outreach, and a follow-up date. Do not send a real message in the base demo.
5. **Market and skills** — show proposed evidence, human review, demand signals, and a linked personal skill plan.
6. **Preparation** — show tracks, a two-week sprint, one focused task, and a preserved practice result.
7. **Weekly review** — distinguish live measurements from an immutable snapshot and append-only reflection.
8. **Profile** — show that search preferences are durable local data and drive personalization.

## Short demo-video set

Keep each clip narrow and outcome-led:

- **01 — Install to first screen (60–90 seconds):** Docker-first setup, local folder contract, demo choice, and healthy app.
- **02 — First useful outcome (90 seconds):** profile, one opening, evidence, and one explicit decision.
- **03 — Daily discovery import (60–90 seconds):** synthetic three-opening workbook, sync, replay protection, and ranked review.
- **04 — Application evidence (90 seconds):** resume variant, exact submitted PDF, stage event, and follow-up.
- **05 — Referral path (90 seconds):** profile-aware search, editable draft, human review, and tracked outreach.
- **06 — Preparation and accountability (90 seconds):** sprint task, practice evidence, weekly snapshot, and reflection.
- **07 — Codex-assisted workflow teaser (90 seconds):** guided browser navigation and drafting with a clear stop before any external send or submission.

Each recording should state that companies and people are fictional and that V1 is local, single-user, and unauthenticated.
